# Aspect Ratio Calculator

A modern, elegant web application for calculating and visualizing aspect ratios. Try it out here: [Aspect Ratio Calculator](https://sooneet-psd.github.io/aspect-ratio-calculator-web/)

## Features

- **Simple Interface**: Clean and intuitive design for easy dimension input
- **Real-time Calculation**: Instantly see the simplified aspect ratio as you type
- **Visual Preview**: Dynamic preview box that updates in real-time
- **Common Ratio Detection**: Automatically identifies and labels common aspect ratios:
  - 16:9 (Widescreen HD)
  - 4:3 (Standard)
  - 21:9 (UltraWide)
  - 32:9 (Super UltraWide)
  - 1:1 (Square)
  - 4:5/3:4 (Portrait)
  - 9:16 (Mobile)

## Design Features

- **Modern Dark Theme**: Sleek dark mode interface for reduced eye strain
- **Geometric Patterns**: Animated background patterns for visual interest
- **Glassmorphism Effects**: Modern glass-like UI components with blur effects
- **Responsive Design**: Works perfectly on all device sizes
- **Smooth Animations**: Subtle transitions and animations for a polished feel

## Technologies Used

- HTML5
- CSS3 (with modern features like CSS Variables, Flexbox)
- JavaScript (Vanilla JS)
- Google Fonts (Inter)

## How to Use

1. Enter the width in pixels
2. Enter the height in pixels
3. See the simplified aspect ratio instantly
4. View the visual representation in the preview section

## Development

To run this project locally:

1. Clone the repository
```bash
git clone https://github.com/sooneet-psd/aspect-ratio-calculator-web.git
```

2. Open `index.html` in your browser
